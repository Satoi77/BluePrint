# BluePrint 使用说明

> 本地运行的**项目功能蓝图可视化系统**：把代码库（任意语言）的**功能结构**画成一张可钻取、可编辑的蓝图。

---

## 一、它是什么

BluePrint 不管理文件版本（那是 Git 的事），它管理**功能结构**：

```
根 → 主干 → 枝干 → 树叶
（系统总入口 → 大功能块 → 子功能 → 原子功能/函数）
```

- **功能结构由 AI Agent 读代码生成**（`blueprint.json`），BluePrint 只负责导入、渲染、Git 状态增强。
- 支持任意语言（Python / JS / TS / Vue / React / Java / Go / C / C++ / C# / Rust / Shell…），前后端同一业务归入同一大功能块。
- 本地运行，数据存本地 SQLite，断网可用。

---

## 二、环境要求

- Windows（已在 Windows 上开发验证）
- Python 3.12+
- Node.js 20+ / 22+
- Git（用于读取提交状态）

---

## 三、安装（首次）

```bat
:: 后端依赖
cd backend
pip install -r requirements.txt

:: 前端依赖（国内镜像）
cd ..\frontend
npm install --registry=https://registry.npmmirror.com
```

---

## 四、启动

**一键启动（推荐）**：双击项目根目录的 `start.bat`，自动启动后端(8000)与前端(5173)并打开浏览器。关闭弹出的两个命令行窗口即停止。

**手动启动（两个终端）**：

```bat
:: 终端 1 — 后端
cd backend
python -m uvicorn app.main:app --port 8000

:: 终端 2 — 前端
cd frontend
npm run dev
```

浏览器打开 **http://localhost:5173/**。

## 六、快速上手

1. 在顶部「项目地址」输入框粘贴一个**含 `.git` 的项目目录**，点「扫描」。
   - 系统会递归扫描源码、读取 Git 提交历史、生成蓝图并**自动保存到本地数据库**。
2. 顶部面包屑默认显示「根」：画布显示**总入口 + 主干（大功能块）**。
3. **点某个主干** → 镜头拉近，展开它的**下一级（枝干）**；再点 → 展开**树叶（原子功能）**。
4. **点画布空白处** → 返回上一级；一直点可回到「根 + 主干」。
5. **点某个圆圈** → 自动居中；其上下游链路高亮，其余连线变暗。
6. 悬停圆圈 → 显示详情（状态、最近提交、文件、函数）。
7. 顶部「全部原子功能」按钮 → 一次显示**全部原子功能**及其调用关系；再点或点空白退出。

## 七、项目管理（左上角 ☰ 菜单）

点左上角**汉堡图标**打开菜单：

| 功能 | 说明 |
|------|------|
| 新增根功能 | 在空白蓝图里新建一个顶层大功能块 |
| 删除当前项目 | 删除当前项目及其蓝图 |
| **创作模式** | 打开后可在画布上自顶向下设计（见下） |
| 新建空白项目 | 填「项目名称」+「项目地址」（地址可留空）→ 新建一张空白蓝图 |

- 顶部**项目下拉**可切换/读取已保存的项目。
- 启动时会**自动恢复上次打开的项目**。
- 所有操作**自动保存**，无需手动保存。

---

## 八、创作模式（自顶向下设计软件架构）

在 ☰ 菜单里勾选「创作模式」：

- **箭头方向反转**为「上级 → 下级」（设计视角）；浏览模式为「下级 → 上级」（阅读视角）。
- 用「新增根功能」建大功能块；选中节点后在右侧编辑面板「新增子节点 / 新增同级」。
- 悬停圆圈出现一个蓝点，从蓝点拖到别的圆圈即可**手动连线**；点连线可删除。
- 画布支持**滚轮缩放**、**中键/左键拖拽平移**。

---

## 九、编辑功能（右侧编辑面板）

选中任意功能节点 → 右侧出现编辑面板：

- 修改**名称 / 描述 / 层级 / 父功能 / 文件 / 符号 / 孤立标记**。
- 「保存」「新增子节点」「新增同级」「删除（级联子节点）」。
- 软件自动补齐的**树叶（原子功能）为派生节点**，只读；要改归属请编辑其上层。

---

## 十、搜索

顶部搜索框**只搜功能名**，支持**模糊匹配**：

- 输入关键词 → 下拉列出匹配的功能（带层级标签），按匹配度排序。
- **点击某条结果** → 自动跳转到该功能所在的结构位置并居中。
- 回车选第一条，Esc 清空。

---

## 十一、导出结构化说明（回喂 Agent）

顶部「导出说明」→ 下载 `blueprint_spec.md`：功能层级树 + 功能关系 + 孤立功能 + **可重新导入的 JSON**。

把这份文件交给 AI Agent，即可据此**修改代码**；改完让 Agent 重新生成蓝图再导入。

---

## 十二、日志

- 后端日志写入本地 SQLite，前端日志写入浏览器 IndexedDB。
- 左下角「日志导出」面板：选择起止时间与级别 → 导出前后端日志。

---

## 十三、多语言与 Agent 建图

功能结构由 Agent 产出。项目内置规范与 skill：

- 规范：`docs/蓝图生成规范.md`
- Skill：`.opencode/skills/blueprint-generation/SKILL.md`（含**可直接复制的提示词模板**）

**流程**：

```
Agent 读全量代码 → 产出 blueprint.json → POST /api/projects/{id}/blueprint → 渲染
```

无 Agent 蓝图时，系统降级为按目录分组展示，开箱可用。

---

## 十四、数据存储

- 数据库：`backend/data/blueprint.db`（项目、蓝图、节点位置、日志）。
- 蓝图数据可随时删除；删除项目会一并清除其蓝图与位置。

---

## 十五、常见问题

| 现象 | 处理 |
|------|------|
| 扫描报错「目录中未找到 .git」 | 指定的目录必须是 Git 仓库根（含 `.git`） |
| 扫出来是空的 | 该系统只解析 Python 源码做文件级扫描；其他语言请用 Agent 生成蓝图导入 |
| 连线看不见 | 默认是暗线，点选功能后其链路才高亮 |
| 前端无法连接后端 | 确认后端已在 8000 端口启动，且浏览器访问的是 5173 |
| 端口被占用 | 关闭占用 8000/5173 的进程，或修改启动端口 |
